# RocketCraft Roadmap

## Goal

A 2.5D side-scrolling shooter with an original blocky, cube-built look. The feel is **tough and tense**: fewer enemies, but each one matters, and dodging is as important as shooting. The ship starts with a simple weapon and gets stronger through upgrades.

- [x] Step 1: ship, shooting, scrolling blocky terrain
- [x] Live on GitHub Pages

## Next (must have)

## Later (polish)

- [ ] Levels with different themes (sky, cave, lava)
- [ ] Boss fight
- [ ] Sound effects and music

- [ ] High score saved in the browser
- [ ] Mobile touch controls

## Ideas / notes

- Tough and tense: enemies should be dangerous, so keep waves small and make dodging matter.
- Weapon upgrades: start with simple shots, then collect power-ups for spread or stronger shots.
- Two-player on one screen (a friend joins on the same keyboard). Big feature, so plan it before building.
- Boss fights at the end of each themed world.
- High scores matter, so show the best score on screen.

## Rules

- Everything original: no copied art, sounds or names.
- One feature at a time.
- Test, then commit and push.
